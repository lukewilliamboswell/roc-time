# Reporting a vulnerability

Please report security vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/lukewilliamboswell/roc-time/security/advisories/new).
Include the affected revision or release, compiler version, a minimal
reproduction, and the expected impact. Avoid including secrets or personal data.

Private vulnerability reporting must be enabled in the repository settings for
that form to accept reports. If it is unavailable, open a public issue asking
for a private reporting channel without including vulnerability details.
