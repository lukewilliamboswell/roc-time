= roc-time 0.3.2

This patch release keeps the published examples building with the current Roc
nightly. The package API and behavior are the same as 0.3.1.

`nightly-2026-10-27-de79a0f` adds a builtin `Stream` type, which basic-cli
0.25.0 shadows; the resulting warning failed the examples that use that
platform. They now use basic-cli 0.26.0.

basic-cli 0.26.0 reports the system clock as a signed `Utc` instant rather
than substituting zero for a pre-epoch clock. The `clock_deadline` example now
accepts pre-epoch readings, floors nanoseconds to microseconds explicitly, and
still rejects a reading outside roc-time's range.

The examples archive is bound to this release's packages.
