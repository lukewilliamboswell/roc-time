# roc-time 0.2.0

This release expands calendar, recurrence and interchange support, and runs on
the current Roc nightly. It includes complete example applications bound to the
released packages, plus an archived API reference.

Calendar APIs now cover Gregorian and Julian conversion, calendar queries and
explicit calendar arithmetic. Recurrence APIs support bounded, resumable date
and timed schedules, with checked iCalendar import and export, exceptions and
cancellations. Interpretation keeps local selections, appointments, gaps and
folds distinct; named-zone data remains an optional companion package.

Additional examples demonstrate meeting exchange, historical archive search,
availability, invoice reporting and named-zone appointments. Download the
examples archive below to run them against this release.

Package headers now float on the nightly compiler. Use the tested compiler
listed below when reproducing a result. Repository automation runs separately
on a Blueprint-pinned compiler. Releases verify every uploaded asset before
publication; versioned API documentation is restored from those same assets.

The supported standard profiles and limits remain documented in each module;
these APIs do not claim complete ISO 8601, EDTF or RFC 5545 support.

Thanks to Kip Cole and the Tempo contributors for the ideas behind roc-time's
interval-oriented model.
